# Course requirements → code

Cravio was built as the CSE 216 (Database Sessional) course project. This file
maps every item on the course checklist to the exact place in this repository
where it is implemented, so it can be checked without reading the codebase.
The checklist text itself is in
[course-checklist.md](course-checklist.md). Every link below is a
permalink pinned to commit
[`cd1d758`](https://github.com/Shafi-8832/Cravio/commit/cd1d7584a89f208ff9af85ab5b1c862e58c60990),
so the line numbers stay correct as the project moves on. "How to verify" is a
string to Ctrl+F or an object name to look for — a few seconds each.
